Hola!

Esto es un proyecto personal para poner en practica todos mis conocimientos adquiridos en mi instituto.

"mineblog.com" es un blog creado para unir la comunidad de Minecraft con el objetivo de aprender mecanicas y crafteos del juego gracias a las guías y artículos que
se suben a la página, también entra la categoría de noticias del propio juego en caso de que quieran saber sobre ultimos cambios o actualizaciones. 
Ademas de poder subir mods, texturas y poder jugar una version demo del mismo juego. Tambien tiene una chat global por si quieren interactuar con la comunidad y
poder hacer amigos.

Tecnologías:

Frontend:

-HTML, CSS y JavaScript (nativo)

Bakcend:

-TypeScript + PostgreSQL (Supabase)

Frameworks:

-Backend: NodeJS

Nota:
Esta web aun esta en fase de desarrollo, por lo que puede tener errores de diseño y de creación de datos en la base de datos.
